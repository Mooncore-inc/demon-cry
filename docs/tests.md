# Тесты

Описание всех тестов в `tests/test_llm.py`. Тесты проверяют модуль `core/llm.py` — ядро взаимодействия с LLM.

## Запуск

```bash
poetry run pytest tests/test_llm.py -v
```

## Как работают моки

Тесты **не обращаются к реальному OpenAI API**. Вместо этого используются фейковые объекты:

- `MockMessage` — имитирует ответ модели (текст или tool_calls)
- `MockToolCall` — имитирует вызов инструмента (имя + аргументы)
- `MockUsage` — имитирует статистику токенов
- `MockResponse` — имитирует полный ответ API

Это позволяет тестировать логику без сетевых запросов и затрат на API.

## Фикстуры

| Фикстура | Что создаёт |
|----------|-------------|
| `mock_config` | Фейковый конфиг с `iteration_limit=5`, `model="test-model"` |
| `mock_registry` | Фейковый реестр модулей (get_tools_schema, execute) |
| `llm` | Экземпляр LLM с фейковым конфигом и реестром |

## Основные тесты

### `test_run_chain_no_tools`

**Сценарий:** Пользователь задал вопрос, LLM ответила текстом без использования инструментов.

**Проверяет:**
- `content` — текст ответа модели
- `tools_used` — пустой список (никаких инструментов не вызывалось)
- `tokens` — токены посчитались (total=20, prompt=10, completion=10)
- API вызван ровно 1 раз

---

### `test_run_chain_with_tools`

**Сценарий:** LLM вызвала инструмент, получила результат, затем ответила текстом.

**Проверяет:**
- `content` — финальный текст ответа ("Result is done")
- `tools_used` — содержит вызов инструмента (имя + аргументы)
- `tokens` — токены накоплены за 2 итерации (15 + 10 = 25)
- `registry.execute` вызван 1 раз с правильными аргументами (`query="test"`)

---

### `test_process_tool_calls`

**Сценарий:** Два инструмента вызываются параллельно.

**Проверяет:**
- `messages` расширился на 2 элемента (результаты обоих вызовов)
- Каждый элемент имеет `role="tool"` и правильный `tool_call_id`
- `registry.execute` вызван 2 раза

---

## Edge case тесты

### `test_run_chain_invalid_json_in_tool_call`

**Сценарий:** LLM вернула невалидный JSON в аргументах tool_call (`"{invalid json!!!"`).

**Проверяет:** Выбрасывается `json.JSONDecodeError`.

---

### `test_process_tool_calls_invalid_json`

**Сценарий:** То же самое, но в методе `_process_tool_calls`.

**Проверяет:** Выбрасывается `json.JSONDecodeError`.

---

### `test_run_chain_registry_error`

**Сценарий:** Registry вернул ошибку (`{"error": "Unknown module: test_tool"}`).

**Проверяет:**
- LLM всё равно получает результат ошибки
- `tools_used` содержит вызов инструмента
- Цикл продолжается, возвращается финальный ответ

---

### `test_run_chain_iteration_limit`

**Сценарий:** Модель игнорирует `tool_choice="none"` и продолжает возвращать tool_calls до исчерпания лимита.

**Проверяет:**
- `content` = `None` (ответ не получен)
- `tools_used` содержит 2 вызова (по одному за итерацию)
- API вызван 2 раза (больше нельзя — лимит исчерпан)

---

### `test_run_chain_empty_response`

**Сценарий:** Модель вернула пустой ответ (нет текста, нет tool_calls).

**Проверяет:**
- `content` = `None`
- `tools_used` = `[]`
- Токены посчитались (total=5)
